# Portfólio Pessoal - Arthur Lemos

Este projeto é um portfólio pessoal desenvolvido em HTML, CSS e com o uso de bibliotecas externas para ícones e fontes. O objetivo é apresentar informações profissionais, acadêmicas, habilidades técnicas e projetos desenvolvidos.


## 📄 Descrição

O site contém:
- **Navbar fixa** com navegação entre seções.
- **Header de apresentação** com foto, nome, título e links sociais.
- **Sobre Mim:** breve apresentação pessoal.
- **Experiência:** principais experiências profissionais.
- **Currículo Acadêmico:** histórico acadêmico e cursos complementares.
- **Habilidades:** habilidades técnicas apresentadas com ícones.
- **Projetos:** principais projetos desenvolvidos com links externos.
- **Footer:** rodapé com direitos reservados.

## 🚀 Tecnologias Utilizadas

- **HTML5**: estruturação do conteúdo.
- **CSS3**: estilização da página.
- **Font Awesome**: biblioteca de ícones.
- **Google Fonts (Poppins)**: fonte personalizada.
